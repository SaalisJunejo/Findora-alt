Built on Next.js App Router under `app/`, with a single root layout (`layout.tsx`) that injects global fonts (Geist), Vercel Analytics, and Tailwind globals. Each route is a folder containing a `page.tsx` — public entry points are `/`, `/login`, `/signup`; authenticated flows live in `/dashboard`, `/report-case`, `/report-sighting`. Server-side data fetching happens only on the root page via Supabase Admin to count resolved cases; all other pages are `'use client'` React components that call Supabase client SDK directly or POST to internal API routes under `app/api/` (`create-demo-account`, `dashboard`, `run-matching`, `run-matching-for-case`). The `components/` directory holds reusable UI: `Header.tsx` (auth-aware navigation using Supabase auth state), `LocationPickerMap.tsx` (Leaflet-based map with Nominatim geocoding, dynamically imported with `ssr: false`), and an empty barrel `index.ts`. Dependency direction is one-way: pages import from `@/components/*` and `@/lib/db/supabase*`; components never import pages. Authentication guards redirect unauthenticated users to `/login` before rendering protected content.
