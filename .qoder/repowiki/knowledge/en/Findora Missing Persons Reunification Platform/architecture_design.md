The root project bootstraps a single Next.js App Router workspace where the `app_pages` module provides UI routes and components, `types_and_public` supplies shared TypeScript domain models (users, cases, sightings, matches) consumed by both client and server code, and `supabase/migrations/20260903_initial_schema.sql` defines the PostgreSQL schema with Row Level Security policies that enforce reporter/finder isolation over `profiles`, `cases`, `sightings`, and `matches`. The app communicates with Supabase exclusively through `@supabase/supabase-js`, relying on DB-level RLS rather than custom API endpoints; face recognition is performed client-side using `@vladmandic/face-api` against model weights shipped from `types_and_public`, and match results are persisted back into the `matches` table. A path alias `@/*` in `tsconfig.json` lets all children import shared modules uniformly.
