The module is split into two sibling scopes. `types/index.ts` is a single flat type-only barrel that exports all shared domain models (`User`, `MissingCase`, `Sighting`, `Match`) and their discriminated union enums (`UserRole`, `CaseStatus`, `SightingStatus`, `MatchTier`, `FamilyAction`); it has no runtime dependencies and serves as the single source of truth for the data contract consumed across the rest of the codebase. The `public/` directory holds static assets: Next.js default SVG icons plus three ONNX-based face-recognition model bundles under `public/models/` (SSD MobileNet v1 for detection, face landmark 68-point detector, and face recognition embeddings), each paired with a `-weights_manifest.json` manifest and a `.bin` weight file — these are served verbatim to the browser so client-side inference can load them at runtime.
